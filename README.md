# Практическая верстка — АМИПРОФ

Проект выполнен на чистых HTML, CSS и JavaScript без фреймворков.

## Структура

- `index.html` — разметка страницы
- `css/style.css` — стили и адаптив
- `js/script.js` — меню, аккордеон, анимации, валидация формы
- `assets/` — папка для изображений из макета Figma

## Как запустить

Откройте `index.html` в браузере.

## Важно

Содержимое Figma не удалось получить автоматически в этой среде. Для пиксель-перфект версии нужно заменить текст, изображения, цвета, размеры и отступы на значения из открытого макета или экспортированных ассетов.
